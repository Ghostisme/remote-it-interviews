# Demo food photography

These local JPEGs are used for the assessment's curated image gallery, so the running dashboard does not depend on an image CDN.

Source: [Unsplash](https://unsplash.com), under the [Unsplash License](https://unsplash.com/license). The exact photo IDs and download URLs are recorded in [`scripts/assets.mjs`](../../../../scripts/assets.mjs). Run `node scripts/assets.mjs` from the repository root to download them again. Photos are illustrative; dish descriptions and prices are demo data.
